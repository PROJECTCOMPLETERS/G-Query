# SatQuery AI — Dataset API

## 1. Purpose

The Dataset API manages SatQuery dataset resources.

It provides:

* Dataset creation
* Dataset listing
* Dataset retrieval
* Dataset deletion

The API operates on dataset metadata defined by the MongoDB Dataset Schema.

---

# 2. Create Dataset

## Endpoint

```http
POST /api/v1/datasets
```

## Request

Content-Type:

```text
application/json
```

Example:

```json
{
  "name": "Chennai_Flood_2026",
  "description": "Satellite imagery for Chennai flood analysis",
  "dataset_type": "single"
}
```

## Required Fields

```text
name
dataset_type
```

## Optional Fields

```text
description
```

## Allowed Dataset Types

```text
single
temporal
multimodal
```

## Response

HTTP:

```text
201 Created
```

Example:

```json
{
  "dataset_id": "66f...",
  "name": "Chennai_Flood_2026",
  "description": "Satellite imagery for Chennai flood analysis",
  "dataset_type": "single",
  "processing": {
    "status": "uploading"
  }
}
```

---

# 3. List Datasets

## Endpoint

```http
GET /api/v1/datasets
```

## Response

HTTP:

```text
200 OK
```

Example:

```json
{
  "items": [
    {
      "dataset_id": "66f...",
      "name": "Chennai_Flood_2026",
      "dataset_type": "single",
      "processing_status": "validated"
    }
  ],
  "total": 1
}
```

The list response should remain lightweight.

Large satellite files must not be returned by this endpoint.

# 4. Get Dataset

## Endpoint

```http
GET /api/v1/datasets/{dataset_id}
```

## Response

HTTP:

```text
200 OK
```

Example:

```json
{
  "dataset_id": "66f...",
  "name": "Chennai_Flood_2026",
  "description": "Satellite imagery for Chennai flood analysis",
  "dataset_type": "single",

  "observations": [
    {
      "observation_id": "obs_001",
      "source": {
        "satellite": "Sentinel-1A",
        "sensor": "SAR"
      },
      "modality": "sar",
      "acquisition": {
        "datetime": "2026-08-20T05:30:00Z"
      }
    }
  ],

  "spatial": {
    "crs": "EPSG:4326",
    "bbox": [80.1, 12.8, 80.4, 13.2]

  "files": [
    {
      "file_id": "66a...",

  "processing": {
    "status": "validated"
  }
}
```

# 5. Delete Dataset

## Endpoint

```http
DELETE /api/v1/datasets/{dataset_id}
```

## Responsibility

Deleting a dataset must maintain consistency between:

```text
MongoDB Dataset Document
        +
Associated GridFS Files
```

## Response

HTTP:

```text
200 OK
```

Example:

```json
{
  "dataset_id": "66f...",
  "deleted": true
}
```

---

# 6. Dataset API Rules

1. MongoDB `_id` is exposed as `dataset_id`.
2. Database implementation details are hidden from the frontend.
3. Large files are not returned through normal JSON responses.
4. Dataset deletion must handle associated GridFS files.
5. Dataset types use controlled values.
6. Technical metadata is primarily generated by the Data Engine.
